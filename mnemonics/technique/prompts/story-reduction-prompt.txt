## Procedure — SMASH mode

1. Restrict work to the locked reduction scope. Ignore out-of-scope palaces/pegs.
2. Each merge group → one smashed beast after re-sequencing **in scope**. Pegs not listed stay single-atom.
3. Max 4 pegs per merge group; split larger groups and note splits in the chat note.
4. Schema blending / Anatomical Micro-Loci: zones Z1→Z4; distinct sensory channels; neutral beast body (`is_smashed=1`); each sub-atom has its own maximally compressed concept (first-person core when it fits; optional impersonal ` — Note:` on that `concept`) + verbatim quote; story encodes zone beats.
5. Re-peg **in scope only** (continue after last out-of-scope peg; never restart at `A` unless scope truly starts at `A`); pack beasts **5 per in-scope palace** (remainder < 5 on the last in-scope palace only); collapse empty in-scope palaces; one character per palace.

## Procedure — REMOVE mode

1. Restrict work to the locked reduction scope.
2. Remove atoms whose **current** peg is listed (must be in scope).
3. Bestiary shifting for remaining **in-scope** beasts only; update beast names/pegs without touching earlier study pegs.
4. Rewrite **in-scope** palace/beast/atom rows; preserve verbatim quote excerpts; keep or tighten compressed concepts (first-person core when it fits; optional impersonal ` — Note:` on `concept` only); keep smashed structure when survivors stay zoned.
5. Re-pack **in-scope** survivors **5 beasts per palace** (remainder < 5 only on the last in-scope palace); collapse empty in-scope palaces; one character per palace.
