## OneDrive Share automation (classic Explorer context menu)

**Intent**: Stable AHK+UIA sequence to share the selected file from Windows Explorer (classic context menu), switch link scope to **People in Bosch Group**, then **Copy link**. This avoids brittle Tab counts and uses the UIA anchors in the trees below.

| Step | Goal | Action (input/click) | UIA anchor / selector | Expected state / check | Fallback / recovery | Timeout |
|---:|---|---|---|---|---|---:|
| 0 | Ensure keystrokes hit file list | Focus file list (cycle `F6` up to 6x) | Explorer: `AutomationId=ItemsView` (List) has keyboard focus | `ItemsView` focused; a file remains selected | Re-activate Explorer and retry focus cycles | 1.5s |
| 1 | Open classic context menu | Send `Shift+F10` | N/A (Win32 context menu) | Context menu opens on selected file | If it doesn’t open, try `AppsKey` once | 1.0s |
| 2 | Trigger Share | Type `S`, then `Enter` | N/A (menu accelerator) | OneDrive Share dialog begins opening | If the wrong item was focused, press `S` again then `Enter` | 2.0s |
| 3 | Wait for Share dialog window | Poll windows | `ahk_class WebView2` and title regex `^Share\\b` | Share dialog handle acquired | If multiple matches, prefer the newest/foreground | 20s |
| 4 | Wait for Share main view ready | Wait for footer buttons | Buttons `AutomationId=Footer-button-settings` and `AutomationId=copy-button` | Both elements exist via UIA | If only “Getting ready…” is visible, keep polling | 20s |
| 5 | Open Link settings | Click/Invoke gear | Button `AutomationId=Footer-button-settings` | Link settings view loads | If click fails, try Invoke then Click | 5s |
| 6 | Wait for Link settings view | Wait for Apply | Button `AutomationId=od-ModifyPermissions-apply-id` | Apply button exists | If view didn’t navigate, click Link settings again | 20s |
| 7 | Select Bosch Group audience | Select radio | RadioButton Name contains `People in Bosch Group` | Radio becomes selected | If SelectionItemPattern missing, click the radio | 5s |
| 8 | Apply settings | Click/Invoke `Apply` | Button `AutomationId=od-ModifyPermissions-apply-id` | Navigates back to Share main view | If still in settings, wait then re-check main anchors | 20s |
| 9 | Copy the link | Clear clipboard, click Copy link | Button `AutomationId=copy-button` | Clipboard becomes non-empty and changes | If clipboard unchanged, click Copy link once more | 10s |
