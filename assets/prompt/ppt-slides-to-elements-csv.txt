Task:
Take a slides CSV (output from ppt-content-to-slides-csv, Stage 1) and produce an elements CSV. One row = one compositable image asset for a single slide. Each row must include an image_gen_prompt for an image-generation AI.

This is Stage 2 of a two-stage PowerPoint workflow. Stage 1 plans the deck; Stage 2 decomposes each slide into isolated visual elements.

CRITICAL — image_gen_prompt is subject and framing only. The human supplies all visual style separately (brand prompts, JSON, reference images, custom instructions — Bosch or any other). Those human style inputs are absolute authority and must not be contradicted by image_gen_prompt.

Before processing:

1. Confirm the slides CSV is present (paste or attach).
2. If the slides CSV is missing or lacks a slide_id column, stop and ask the user to provide it.

Inputs:

- Slides CSV: <paste or attach output from ppt-content-to-slides-csv>
- Optional assembly notes: <placement on slide only — not colors or illustration style>

Column schema (authoritative — use exactly these columns in this order):

element_id;slide_id;element_order;element_type;position_region;size_hint;text_to_render;image_gen_prompt;assembly_notes

Column definitions:

- element_id: Stable primary key. Format EL_SLIDE_001_01, EL_SLIDE_001_02, etc. Encode parent slide in the ID.
- slide_id: Foreign key — must match a slide_id from the input slides CSV.
- element_order: Stacking / reading order on the slide (1 = first / back / top-left).
- element_type: One of: title, subtitle, section_label, bullet_group, body_text_block, metric_card, chart_bar, chart_line, chart_pie, icon_badge, illustration, diagram, timeline_segment, process_step, persona_card, comparison_column, callout, divider_line, decorative_shape.
- position_region: Placement hint — e.g. top, top_left, top_center, center, bottom_right, full_width_band, left_column, right_column.
- size_hint: One of: small, medium, large, full_width, full_height.
- text_to_render: Literal text that must appear in the image. Leave empty when the element has no text labels. When non-empty, the same text must appear verbatim inside image_gen_prompt (see sync rule below).
- image_gen_prompt: Minimal subject + framing only. Must include full text_to_render when that column is non-empty. See exact template below.
- assembly_notes: How to place this element on the slide (margins, alignment relative to other elements).

Decomposition rules:

1. Never produce one element that represents an entire slide. Split into title, content blocks, charts, icons, illustrations, cards, etc.
2. Every slide_id from the input must have at least one element. Typical slides have 2–6 elements.
3. Respect decomposition_hints and visual_intent from the slides CSV.
4. For chart_focus or metric_dashboard slides, create separate chart or metric_card elements — one chart per element.
5. Use data_points from the parent slide row when writing chart or metric prompts.
6. Use element_type illustration for standalone illustrative assets that are not charts, icons, or text blocks.

Illustration-specific decomposition:

1. Subject = what to depict, named briefly from slide content (e.g. Titanic ship illustration).
2. Do not add art direction of any kind.

image_gen_prompt template (MANDATORY — every row must match this structure exactly):

Line 1 (priority block — copy verbatim, always first):
HUMAN STYLE AUTHORITY: Any style requirements, brand prompts, JSON files, reference images, or instructions the human provided before or with this message define ALL visual style — colors, typography, illustration style, realism, materials, lighting, backgrounds, and quality rules. They override and replace any conflicting wording below. Do not invent or substitute a different style.

Line 2 (subject — one short sentence):
Subject: [what to depict]

Line 3 (framing — one short sentence):
Framing: isolated element only, not a full slide; [aspect ratio hint if useful].

That is the complete image_gen_prompt. No additional sentences.

text_to_render sync rule (MANDATORY):

- Keep text_to_render and image_gen_prompt as separate columns.
- When text_to_render is non-empty, copy its full content verbatim into the Subject line of image_gen_prompt. The human pastes only image_gen_prompt at image-generation time — never both columns separately.
- When text_to_render is empty, Subject uses chart data from data_points or a brief named subject only.
- text_to_render and the Subject portion of image_gen_prompt must match exactly whenever text_to_render is non-empty. Do not paraphrase, shorten, or omit labels, dates, or timeline entries.

Subject line rules by element_type:

- title, subtitle, section_label, bullet_group, body_text_block: Subject: [exact text_to_render verbatim]
- chart_bar, chart_line, chart_pie, metric_card: Subject: [chart type + labels + values from data_points]. If text_to_render is non-empty, append after a dash: — [exact text_to_render verbatim]
- timeline_segment, process_step, diagram, callout, comparison_column, persona_card: Subject: [brief element label] — [exact text_to_render verbatim]. If text_to_render is empty, Subject: [brief element label from slide content]
- illustration, decorative_shape, icon_badge: Subject: [named subject]. If text_to_render is non-empty, append: — [exact text_to_render verbatim]

FORBIDDEN anywhere in image_gen_prompt (these cause style conflicts with human attachments):

- Colors, hex codes, palettes, brand names
- Font names, weights, typography style
- Illustration style adjectives (2.5D, flat, photorealistic, cinematic, sketch, watercolor, vector, modern, professional)
- Materials, lighting, textures, shadows, glow, halos, edge treatment
- Background color or quality rules (white background, sharp edges, anti-aliasing, resolution)
- "Generate only this isolated UI element" or similar long boilerplate — use the three-line template only

Validation (before output):

- Every slide_id in elements exists in the input slides CSV.
- No duplicate element_id values.
- Every image_gen_prompt is exactly three lines (priority block + Subject + Framing).
- Every image_gen_prompt starts with HUMAN STYLE AUTHORITY:
- No forbidden style language in any image_gen_prompt.
- When text_to_render is non-empty, its full content appears verbatim in that row's image_gen_prompt Subject line.

WRONG (do not output): element\_id, EL\_SLIDE\_001\_01
RIGHT: element_id, EL_SLIDE_001_01
